# Platform invariants

> English | [简体中文](invariants.zh.md)

Load-bearing rules of the codebase. They exist because breaking them produced
real, observed failures (self-closing windows, starved hotkeys, IME breakage,
`languages.undefined` leaks). Read before touching the related paths; every
item here is a "fix the code, never the rule" case.

## Frontend

| #   | Invariant                                                                                                                                                                                                                                      | Why                                                                                                                                             |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `setConfig()` debounces, batches and broadcasts `<key>_changed`; `writeThrough()` persists immediately and cancels a pending write for the same key                                                                                            | the window may vanish mid-write (hotkey bindings, service-instance modal save/delete) — `setConfig()` lands the hotkey after the window is gone |
| 2   | `setConfigRaw` rejects `undefined` / `null`; never `store.set(key, undefined)`                                                                                                                                                                 | a cleared key leaks `prefix.undefined` through `t('prefix.${value}')` into dropdowns                                                            |
| 3   | Service lists go through `sanitizeServiceInstanceList`; every consumer degrades gracefully on unknown names                                                                                                                                    | restored backups may contain keys of removed services. Builtin names: `openai` (translate), `paddle` / `system` / `openai` (recognize)          |
| 4   | Legacy pot backups must always restore: backup validation checks only `type: 'config-backup'`, never an `app` field                                                                                                                            | compatibility red line; regression case in `scripts/test-webdav.ts` ("Legacy pot backups still restore")                                        |
| 5   | `$effect` tracks synchronously — one-shot loading goes through `untrack(...)` or an once-guard; non-reactive bookkeeping takes `// eslint-disable-next-line svelte/prefer-svelte-reactivity` (`src/windows/translate/App.svelte` is the model) | reading a freshly built array/object inside an effect re-runs it every frame (the fresh-array-deps trap — it caused a focus-oscillation bug)    |
| 6   | Seed `$state` from props through a closure function (`seededConfig()`)                                                                                                                                                                         | bare prop reads at construction trip svelte-check under `--fail-on-warnings`                                                                    |
| 7   | Tests must call `unmount()`                                                                                                                                                                                                                    | `$effect` does not clean up across vitest cases; `render()`'s `unmount()` is the only listener/DOM cleanup                                      |
| 8   | New i18n keys land in `en_US.json` / `zh_CN.json` / `zh_TW.json` at least; new locales register in `LOCALE_FILES` (`i18n.svelte.ts`); keys live under `common.*` or a business namespace                                                       | other locales fall back via `FALLBACK_CHAINS`; i18next prints missing keys verbatim                                                             |
| 9   | OS branches compare v1 names (`Windows_NT` / `Darwin` / `Linux`) via the single normalization point `normalizeOsType()` in `src/lib/utils/env.svelte.ts`                                                                                       | plugin-os v2 returns lowercase `'windows' \| 'macos' \| 'linux'`; unnormalized values broke the system-OCR icon                                 |
| 10  | `@tauri-apps/cli` stays in devDependencies; Node.js >= 22 on PATH                                                                                                                                                                              | `bun run` shells out to node-shebang bins (vite, vitest, svelte-check, tauri CLI) — Bun does not replace them                                   |

## Backend

| #   | Invariant                                                                                                                                                                                                                                                                                   | Why                                                                                                                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Every Tauri command that can exceed ~10 ms (full-screen capture, PNG encode, WinRT OCR `block_on`, file IO) is `#[tauri::command(async)]`; background WinRT threads call `CoInitializeEx(COINIT_MULTITHREADED)` first (the main thread is STA, owned by tao — `system_ocr.rs` is the model) | WM_HOTKEY is dispatched by the main WndProc; a blocked event loop starves every global hotkey ("registered but never fires")                       |
| 2   | No `unwrap()` on the hotkey / tray / window paths — `let _ = ...` plus `log::warn!`                                                                                                                                                                                                         | DPI anomalies, display enumeration and window-attribute failures are real on Windows and kill the process silently                                 |
| 3   | Focus the translate window on demand, once, after checking `isVisible()` / `isFocused()`; never chain `.focused(true)` on hidden window creation                                                                                                                                            | tao `set_focus()` injects synthetic ALT keystrokes when `SetForegroundWindow` is refused — it breaks IME composition and steals focus back         |
| 4   | The close-on-blur three-layer protection is load-bearing: 800 ms programmatic-focus grace (`src/windows/translate/focus.ts`), `isFocused()` recheck before confirming, drag/focus cancel                                                                                                    | WebView2 oscillates focus on transparent borderless windows; a bare blur timer closes the window under the user's hands                            |
| 5   | `tauri.windows.conf.json` `additionalBrowserArgs` stays in sync with `BROWSER_ARGS` in `src-tauri/src/window.rs`; never add `--disable-web-security` to the daemon window                                                                                                                   | WebView2 shares one process across windows; without the `Origin` header the IPC layer rejects every invoke (white screen, `missing Origin header`) |
| 6   | Plugin command "not found" triage order: ① `generate_handler!` registration, ② cargo feature gate (`tauri-plugin-fs` ships `watch` behind a non-default feature), ③ capabilities coverage for the window label                                                                              | three different layers can each hide the command                                                                                                   |
| 7   | `tauri-plugin-log` keeps `TimezoneStrategy::UseLocal`                                                                                                                                                                                                                                       | user-facing timestamps otherwise shift by the timezone offset                                                                                      |

## Test infrastructure quick facts

- Seed through `fakeConfigFile` → `await initConfigStore()` → `render(Component)`; never seed via `setConfig()` (writes are debounced, the assertion would race).
- **UndefinedSweep**: walk the DOM right after `render()` and again after settling (`src/windows/config/ConfigWindow.test.ts` is the model).
- **Mocks must be honest**: a mock returns what the real plugin returns (plugin-os gives `'windows'`, not `'Windows_NT'`), or tests stay green while the real machine fails.
- **Revert the fix, watch the test fail** (`git stash push <file>` … pop) — a regression test that never fails is not a test.
- bits-ui Dialog scroll-lock can leak `pointer-events: none` onto `document.body` across vitest cases; the test setup scrubs body inline styles — suspect cross-test leakage, not the component.
